# ⚡ DanClick

**DanClick** — браузерный кликер с уровнями, магазином, автоматическим заработком и системой прогресса.

## 🎮 Возможности

- 🖱️ Кликер и система уровней
- 🛒 Магазин: сила клика, автокликер, множитель и критический клик
- 🔥 Комбо и критические клики
- 🎁 Ежедневный бонус
- ♻️ Система престижа
- 💎 Кристаллы
- 🎨 Скины кнопки
- 🔊 Звуковые эффекты
- 🏆 Расширенные достижения
- 📋 Локальный рейтинг рекордов
- 💾 Автосохранение через localStorage
- 📱 Адаптация под мобильные устройства

## 🚀 Запуск

Скачай репозиторий и открой **index.html** в браузере. Установка сервера не требуется.

## 📁 Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Интерфейс игры |
| `style.css` | Дизайн, адаптивность и анимации |
| `script.js` | Игровая логика, магазин и сохранение |

## 💎 Как работает прогресс

Прогресс хранится в **localStorage**, поэтому он сохраняется на конкретном устройстве и в конкретном браузере.

Престиж позволяет сбросить обычный прогресс за кристаллы. Кристаллы используются для покупки скинов.

## 🏆 Рейтинг

Сейчас рейтинг локальный: рекорды хранятся только в браузере пользователя. Для общего онлайн-рейтинга понадобится серверная база данных и API.

## 🌐 GitHub Pages

В репозитории открой **Settings → Pages → Deploy from a branch → main**, чтобы опубликовать игру как сайт.
