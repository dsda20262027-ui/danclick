# ⚡ DanClick

**DanClick** — это простой браузерный кликер, который превращается в настоящую маленькую игру: кликай, зарабатывай монеты, покупай улучшения и повышай уровень!

## 🎮 Возможности

- 🖱️ Кликер с подсчётом монет
- 🆙 Система уровней
- 🛒 Магазин улучшений
- 👆 Улучшение силы клика
- 🤖 Автокликер
- 🚀 Множитель дохода
- 🔥 Комбо за быстрые клики
- 🏆 Достижения
- ✨ Анимация получения монет
- 💾 Автоматическое сохранение прогресса
- 📱 Адаптация под мобильные устройства

## 🚀 Как запустить

1. Скачай репозиторий.
2. Открой файл **index.html** в браузере.
3. Нажимай кнопку **«КЛИК!»**.
4. Покупай улучшения и прокачивайся.

Никакая установка или сервер не нужны — игра работает прямо в браузере.

## 📁 Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Интерфейс игры |
| `style.css` | Дизайн и анимации |
| `script.js` | Игровая логика и сохранение |

## 💾 Сохранение

Прогресс сохраняется в **localStorage** браузера. При повторном открытии игры прогресс остаётся на этом устройстве и в этом браузере.

## 🛠️ Технологии

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 🌐 GitHub Pages

DanClick можно разместить как сайт через **GitHub Pages**.

Открой:

**Settings → Pages → Deploy from a branch → main**

После публикации GitHub Pages выдаст ссылку на игру.
